# Code of Conduct

This project expects respectful, constructive participation.

## Expected Behavior

- Be kind and direct.
- Assume good intent, especially in technical disagreements.
- Keep discussions focused on the project.
- Give actionable feedback.
- Respect privacy and do not share sensitive Slack or local machine data.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Sharing private Slack data, credentials, or screenshots without consent.
- Repeated off-topic disruption.
- Personal attacks.

## Enforcement

Maintainers may edit, hide, or remove comments and may block participants who repeatedly ignore these expectations.

If you need to report a concern, use the repository's private maintainer contact path when available.
